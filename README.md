# SlidePanel

A macOS menu bar app (Electron) with a slide-out web panel.

- Toggle the panel with Option+Space.
- Tabs for Claude, ChatGPT and Gemini; Cmd+N starts a new chat on the current site.
- Scripts that fill in and submit one query on those sites.

## Run

    npm install
    npm start

Build a DMG with `npm run dist:dmg`.
